Quick Installation (3 Simple Steps)

  1. Place the website_daisy folder into your Odoo custom addons directory.
  2. Restart your Odoo server and enable Developer Mode in Settings.
  3. Go to Apps, click Update Apps List, search for "Daisy Theme", and click Activate!
